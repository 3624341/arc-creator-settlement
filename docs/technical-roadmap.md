# Technical Roadmap

## Milestone 1 — Arc Testnet MVP

**Goal:** Ship a working milestone escrow flow on Arc Testnet.

Deliverables:

- Next.js product interface
- EscrowFactory and MilestoneEscrow smart contracts
- Arc Testnet deployment
- USDC approve/deposit/release flow
- ArcScan transaction links
- Public GitHub repository

## Milestone 2 — Circle Wallets Integration

**Goal:** Reduce Web3 onboarding friction by adding Circle wallet infrastructure.

Deliverables:

- Circle Developer-Controlled Wallet setup
- User wallet creation flow
- Server-side wallet action routes
- Transaction signing flow documentation
- Wallet status dashboard

## Milestone 3 — Circle Contracts + Observability

**Goal:** Make deployment and contract monitoring grant-review friendly.

Deliverables:

- Circle Contracts deployment path
- Event indexing for FundsDeposited, MilestoneSubmitted, PaymentReleased
- Supabase-backed settlement history
- Dune or public analytics dashboard

## Milestone 4 — Gateway-Powered Cross-Chain Funding

**Goal:** Let businesses fund Arc escrows from USDC balances on supported external chains.

Deliverables:

- Gateway proof-of-concept
- Cross-chain funding demo
- Unified funding UX
- Documentation for marketplace integration

## Milestone 5 — Mainnet Pilot

**Goal:** Launch a controlled pilot after Arc mainnet readiness.

Deliverables:

- Production deployment checklist
- Security review of escrow contracts
- 5-10 pilot contracts with creators or freelance users
- Marketplace integration roadmap
